# Отчет по этапам frontend

Дата начала: 26.09.2026. Ветка: `codex/purtov-frontend`. Данные `train/test` с фактическими временами прибытия не используются.

## F01. Каркас проекта — выполнено

- Созданы Vite + React + TypeScript, Tailwind и MapLibre, скрипты `dev`, `typecheck`, `build`, `preview`.
- Зависимости закреплены в `package-lock.json`.
- Проверка: `npm run build` успешно (Vite 8.3.1). В ограниченной среде сборка не смогла запустить нативный модуль; повторный разрешенный запуск прошел.

## F02. Типы и демо-данные — выполнено

- Перенесены типы из `contracts/schemas.py`; добавлена базовая проверка входного WebSocket-сообщения.
- Скопирован пример `contracts/examples/ws_snapshot.json`; подготовлены сценарии `normal`, `empty`, `many`, `disconnected`.
- Созданы локальные демонстрационные маршруты и функции времени/форматирования/геометрии.
- Маршруты явно синтетические: времена и ID остановок в исходном JSON-примере не совпадают с опубликованным плановым CSV. Фактические ответы validate не использованы.
- Проверка: `npm run typecheck` успешно.

## F03. Рабочий экран — выполнено

- Собрана адаптивная диспетчерская: статус, суммарные показатели, панель управления, очередь предупреждений, карта и карточка борта.
- На ширине около 810 px панели перестраиваются в вертикальный сценарий. Проверено в браузере.

## F04. Карта — выполнено

- Добавлены локальный стиль MapLibre без сетевых тайлов, маршрут, пройденный путь, остановки, цветовые маркеры риска, масштабирование и выбор борта.
- Визуальная проверка выявила нулевую высоту canvas из-за конфликта CSS с MapLibre. Исправлен порядок стилей и селектор контейнера; линия и маркер видны в браузере.

## F05. Очередь и карточка — выполнено

- Приоритетная лента алертов связывает выбранный борт с картой и карточкой. Карточка показывает прогноз, интервал q10–q90, вероятность, причину и рекомендацию.
- Состояние выбранного борта и счётчики сверены с контрактным снимком в браузере.

## F06. Воспроизведение — выполнено

- Демо-снимок стал детерминированной временной шкалой: 5 модельных секунд в 1 секунду, перемещение бортов, второй алерт через 45 модельных секунд, пауза и перезапуск.
- Проверка: второй алерт появился на экране; его выбор обновил карточку, маршрут и диаграмму; пауза остановила часы.

## F07. Диаграмма движения — выполнено

- Построены линия плана, проекция наблюдений на маршрут и q10–q90 с центральной оценкой прогноза для выбранной цели.
- Проверка: диаграмма меняется при выборе борта, оси и легенда видны в браузере.

## F08. Крайние состояния — выполнено

- Добавлены пустой поток, большой список алертов, потеря связи, устаревшие позиции, отсутствие маршрута и безопасное ожидание данных.
- Проверка: сценарии «Нет данных», «Пик алертов», «Потеря связи» переключены в браузере. Пустой сценарий не оставляет старую карточку.

## F09. Адаптер живого режима — выполнено на тестовом источнике

- WebSocket `/ws/live` с проверкой кадров и автоматическим переподключением; REST `/api/v1/tracks/{tr_id}` с отменой предыдущего запроса.
- Добавлен локальный тестовый источник `npm run dev:stub` на порту 8000. При переключении на live карта, карточка и диаграмма получили данные через Vite proxy.
- Проверка: остановка тестового источника вывела «НЕТ СВЯЗИ» и пометила позиции устаревшими; повторный запуск восстановил статус LIVE. Совместимость с настоящим backend пока не проверена: сервиса в репозитории нет.

## F10. Упаковка и сборка — выполнено, Docker не запущен

- Добавлены многоэтапный Dockerfile, nginx на порту 3000 и прокси `/api`/`/ws` на `backend:8000`, `.dockerignore`, README.
- `npm run typecheck` и `npm run build` прошли. Production-сборка открыта в preview: карта, алерты и карточка отображаются, ошибок браузера нет.
- Контрактный снимок прошёл runtime-проверку; кадр с повреждённой вложенной причиной прогноза отклонён.
- Исправлена упаковка MapLibre worker: теперь worker собирается Vite вместе с зависимостями.
- Docker CLI установлен, но Docker Desktop daemon не запущен (`docker info` не может подключиться к `dockerDesktopLinuxEngine`), поэтому `docker build` и запуск контейнера не проверены.

## F11. Самопроверка интерфейса — выполнено

- Проверены ширины примерно 810, 1366, 1920 и мобильная 375 px. На 375 px горизонтальная прокрутка страницы отсутствует; диаграмма прокручивается внутри своей панели.
- Проверены выбор борта из алерта, синхронизация карты/карточки/диаграммы, пустое состояние, пик алертов, обрыв и восстановление потока.
- Для высокого рабочего экрана увеличена высота рабочей области, чтобы рекомендация оставалась видимой без прокрутки карточки.

## F12. Материалы для показа — подготовлены

- Создан `docs/DEMO_SCRIPT.md`: действия и реплики для двухминутного показа, план кадров и контроль перед записью.
- Видеозапись не создавалась: в репозитории нет готового ролика и пользователь не предоставлял формат или место публикации. Экран и сценарий готовы к записи.
