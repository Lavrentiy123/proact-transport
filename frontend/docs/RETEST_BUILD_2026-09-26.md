## Найдено и исправлено

1. После исправления склонения счётчика первая Docker-сборка обнаружила неполное покрытие категорий `Intl.PluralRules` (`zero`, `two`). Словарь дополнен; локальная и Docker-сборки затем прошли.
2. Первый запуск контейнера остановился с `host not found in upstream "backend"`. nginx теперь разрешает это имя при запросе через Docker DNS; автономный демо-режим и прокси проверены повторно.
3. При отсутствии backend DNS-ответ задерживал ошибку живого режима. `resolver_timeout 2s` ограничил ожидание; после изменения REST и WebSocket прокси снова дали 200 и `snapshot` при наличии backend.

## Ограничения

- Настоящий backend отсутствует в текущем репозитории. Интеграция A08 проверена на локальном тестовом потоке, не на командном backend.
- Vite предупреждает о крупном JavaScript chunk: основной файл около 359 КБ gzip, worker MapLibre около 510 КБ без gzip. Это предупреждение о размере, не ошибка сборки.
- Отдельного автоматического `npm test` в проекте пока нет; поведение интерфейса проверено в браузере и описано во втором отчёте.
