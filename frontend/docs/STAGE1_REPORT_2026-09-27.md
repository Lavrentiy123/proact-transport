## 7. Как воспроизвести

```bash
cd frontend
npm ci
npm run typecheck
npm run test:contracts
npm run build
```

Stub-кейсы: `STUB_CASE=status-skew npm run dev:stub` и `STUB_CASE=rewind npm run dev:stub`, затем `npm run dev` и открыть `http://localhost:5173/`.

Стенд из корня репозитория:

```bash
docker compose up --build -d
```

Затем открыть `http://localhost:3000/`. Перемотка: `POST http://localhost:8000/api/v1/replay/control` с телом `{"start_at":"2026-01-06T07:00:00"}`. Деградация: `docker compose stop replay`, затем `docker compose start replay`.
