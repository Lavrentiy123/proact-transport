# Сценарий показа frontend (около 2 минут)

## Подготовка

1. Запустить `npm ci` и `npm run dev` из `frontend/`, открыть `http://localhost:5173`.
2. Выбрать **Демо-сценарий → Обычный поток**, нажать **Начать заново** и сразу **Пауза**. Для записи использовать окно от 1366 px шириной, масштаб браузера 100%.
3. Убедиться, что видны три борта, один красный риск, карта и диаграмма. Демо не требует backend; географическая подложка загружается из сети, а при её недоступности появляется схема маршрута.

## Реплики и действия

| Время | Действие | Что сказать |
|---|---|---|
| 0:00–0:20 | Показать общий экран, статус REPLAY, счётчики. | «Это экран диспетчера: борта, предупреждения и прогноз прибытия на 10–15 минут вперёд собраны в одном месте». |
| 0:20–0:45 | Указать на красное предупреждение и карточку. | «Для этого борта прогноз +6 минут 12 секунд. Видны диапазон неопределённости, причина затора и рекомендация». |
| 0:45–1:05 | Показать линию маршрута и диаграмму план–наблюдение–прогноз. | «Положение связано с маршрутом, а диаграмма показывает, где наблюдение расходится с планом и куда попадает прогноз». |
| 1:05–1:25 | Нажать **Продолжить**. Через ~9 секунд при скорости ×5 появится второй алерт. Нажать **Пауза**, выбрать борт 122658. | «Предупреждение поступает во время воспроизведения; выбор события одновременно меняет карту, карточку и диаграмму». |
| 1:25–1:45 | Кратко показать сценарии **Нет данных** и **Потеря связи**, затем вернуть **Обычный поток**. | «При пустом потоке и обрыве связи экран показывает явное состояние, не выдавая старую позицию за новую». |
| 1:45–2:00 | Закончить на обычном потоке и карте. | «Демо работает самостоятельно. Для реального потока frontend переключается на контрактные WebSocket и REST backend». |

## Для записи экрана

- Снять общий план и крупно карточку риска, появление второго алерта, выбор второго борта и диаграмму.
- Скрыть посторонние окна и уведомления. Оставить читаемыми названия, время и легенду.
- Тестовый источник `npm run dev:stub` годится для проверки подключения, но в записи его следует явно назвать тестовым. Реального backend в текущем репозитории пока нет.
- Не утверждать, что демонстрационный маршрут взят из реальных треков или что интерфейс доказывает точность модели. Маршрут синтетический, прогноз взят из контрактного примера.

## Быстрый контроль перед показом

- `npm run typecheck`, `npm run test:contracts` и `npm run build` проходят.
- Карта показывает маршрут и маркер; при выборе второго борта они перестраиваются.
- После **Начать заново** счётчик алертов равен 1; при воспроизведении становится 2.
- Пауза останавливает часы, **Начать заново** возвращает 12:40:00.
- В режиме **Нет данных** нет старой карточки; в **Потере связи** есть красный статус и отметка об устаревании.
