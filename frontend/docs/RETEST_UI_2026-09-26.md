## Изменения по результатам проверки

- Исправлено склонение числа скрытых предупреждений.
- Добавлен доступный с клавиатуры выбор любого борта на карте, включая борта без активного алерта.
- Устранены ошибки TypeScript и запуска nginx, обнаруженные при реальной Docker-сборке и запуске.

## Что ещё нельзя подтвердить здесь

- Совместимость с настоящим backend команды и его данными: в текущем checkout его нет.
- Точность прогнозной модели: интерфейс использует контрактный пример и синтетический маршрут.
- Автоматический accessibility-аудит специализированным инструментом не выполнялся; проверены доступные метки и альтернативный клавиатурный выбор борта.
