  - SDF-формы риска на маркерах: треугольник, ромб, круг, кольцо. Красные крупнее, у выбранного — ореол, у устаревших — обводка.

- **Карточка (3.4).**
  - Порядок блоков: риск → участок и «План · прибытие ≈ · через» → рекомендация с одной основной кнопкой → причина → ключевые значения → What-If (свёрнут) → сведения о расчёте.
  - При обрыве связи кнопки отключены с пояснением «Нет связи — отправка недоступна», у риска и прогноза стоит метка «не обновляется с HH:MM:SS».
- **Марей (3.5).**
  - SVG рисуется в реальных пикселях контейнера (ResizeObserver), подписи 11–12 px на любой ширине.
  - Подпись прогноза «Опоздание 6:12 · 12:58» больше не обрезается, диаграмма заполняет полосу высотой 140–180 px.
- **Состояния связи (3.6).** Баннер «Связь восстановлена в HH:MM:SS» появляется на 5 с после обрыва или застоя. Иконка баннера обрыва — `WifiOff`.
- **Тексты (3.7).**
  - Склонения через одну функцию `plural()`.
  - «Диапазон q10–q90» заменён на «Вероятный диапазон».
  - Служебная строка «Контракт frontend…» — только при `?debug=1`.

**Этап 4 — доступность, безопасность, мелочи**

- Добавлен SVG-favicon: 404 при каждой загрузке больше нет.
- При клике по кластеру учитывается `prefers-reduced-motion`.
- Порты Vite, stub, e2e и метрик настраиваются через `BACKEND_ORIGIN`, `E2E_WEB_PORT` и `E2E_STUB_PORT`.

```bash
cd frontend
npm ci
npm run typecheck
npm run test:contracts
npm run test:unit
npm run build
```

```powershell
$env:PW_CHROMIUM_PATH = "$env:LOCALAPPDATA\ms-playwright\chromium-1223\chrome-win64\chrome.exe"
```
