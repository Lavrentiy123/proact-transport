## 🛰 1. Потоковая телематика движения (Протокол NDTP / CSV / Parquet)
В описании трека прямо указан формат **NDTP (Navigation Data Transfer Protocol)** — отраслевой стандарт телематических терминалов (АСУ НГПТ Мосгортранса / ЭРА-ГЛОНАСС).

Организаторы могут предоставить данные в одном из двух видов:
* **Вариант А (Распарсенный табличный вид — CSV / Parquet):**
  * `vehicle_id` / `device_id` — идентификатор борта или бортового навигационного блока;
  * `route_id` — номер/код маршрута (например, `м3`, `е30`, `т22`);
  * `timestamp` — точное время фиксации точки (UTC / MSK);
  * `latitude`, `longitude` — географические координаты (WGS-84);
  * `speed` — мгновенная скорость ТС (км/ч);
  * `heading` / `course` — азимут/направление движения (0–360°);
  * `validity` / `satellites` / `hdop` — признаки достоверности навигации (для фильтрации шумов GNSS).
* **Вариант Б (Сырые пакеты NDTP / дампы):**
  * Бинарные пакеты навигационного сервиса (NPH / NMS / NAV_DATA);
  * В `src/` будет предусмотрен легковесный парсер пакетов телеметрии.

## 🚏 2. Реестр остановок и геометрия маршрутов (GTFS / Справочники)
* **Справочник остановок:**
  * `stop_id`, `stop_name` (наименование остановки), `lat`, `lon`, `zone_id`.
* **Схема маршрутов и последовательность:**
  * `route_id`, `route_short_name`, `direction_id` (прямое/обратное направление);
  * `stop_sequence` — порядковый номер остановки на рейсе;
  * Полилиния геометрии трассы (Shapes) для Map Matching.

---

## ⏱ 3. Эталонное плановое расписание
* Поля: `trip_id`, `route_id`, `stop_id`, `planned_arrival_time`, `planned_departure_time`, `headway_plan_sec`.
* Сопоставление факта и плана позволяет вычислять:
  * `Schedule Deviation` $\Delta t = t_{\text{fact}} - t_{\text{plan}}$ (отклонение от графика);
  * `Headway` $H_{\text{fact}} = t_{\text{curr}} - t_{\text{lead}}$ (фактический межпоездной интервал).
