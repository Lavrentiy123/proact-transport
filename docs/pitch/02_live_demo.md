# Сценарий живого демо (видео 3 минуты и показ на полуфинале)

Демонстрируем настоящую систему: поток NDTP → прогноз за 10–15 минут → алерт → действие диспетчера → обрыв и
восстановление. Синтетическое демо дашборда (`?source=demo`) — только запасной вариант, если нет Docker.

## Подготовка (до записи, 5 минут)

```bash
docker compose up --build -d          # из корня репозитория
curl http://localhost:8000/ready      # {"status":"ready",…}
```

- Открыть дашборд http://localhost:3000 (на ноутбуке капитана порты в `.env`: http://localhost:13000). Сразу идёт живой
  поток: плашка **LIVE**, время датасета 06.01.2026 с 07:00, скорость ×10.
- Чтобы алерт появился быстрее, перенести время на начало утреннего пика:
  `curl -X POST http://localhost:8000/api/v1/replay/control -H "Content-Type: application/json" -d '{"start_at": "2026-01-06T07:25:00"}'`
  (первый красный алерт — примерно через 20 с; в PowerShell — `curl.exe` и экранированные кавычки, см. `docs/JURY_GUIDE.md` §6).
- Второе окно — терминал в корне репозитория для `bash scripts/chaos.sh`.

## Если что-то пошло не так

- Алерт не появляется дольше минуты → перенести время на 07:25 (команда выше) или выбрать жёлтый/красный борт на карте.
- Карта без подложки (нет интернета или медленный VPN) → схема маршрутов и борта видны сразу, подложка догружается сама; говорим «работает и офлайн».
- Стенд работает долго → replay по кругу: в конце дня время само перематывается на 07:00, режим остаётся LIVE.
- Нет Docker → `?source=demo` (синтетический сценарий) и честно сказать, что это демо интерфейса.
