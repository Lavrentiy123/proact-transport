ПроАкт.Транспорт

Прогноз задержек городского транспорта за 10–15 минут: ml-core (CatBoost + PyTorch через ONNX), backend (приём NDTP, тик прогнозов, алерты) и дашборд диспетчера в Docker.

Документация по коду (pdoc)

  • ML — пакет признаков features, сервис ml_core, обучение и валидация src.ml
  • Backend — NDTP-сервер, replay, тик прогнозов, алерты, REST и WebSocket

Спецификация API (OpenAPI)

  • backend — openapi.json; интерактивный Swagger после запуска: http://localhost:8000/docs
  • ml-core — openapi.json; Swagger после запуска: http://localhost:8001/docs

Запуск и проверка

  • README — быстрый старт (docker compose up --build -d, дашборд на http://localhost:3000)
  • Инструкция для жюри — как подать поток (replay или эмулятор NDTP), где прогнозы, алерты, дашборд и метрики
  • Архитектура · Производительность и надёжность

Модель и данные

  • Карточка модели — признаки, модели, метрики (official, LOBO, FWD, поток), ограничения
  • Анти-утечка — правила, находки и тесты
  • Бизнес-эффект — ожидание пассажиров (EWT), пассажиро-часы и рубли
