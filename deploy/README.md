# Стенд для жюри на ВМ (Yandex Cloud)

Организаторы: «крайне желательно, чтобы вы хостили сервис самостоятельно». Стенд — тот же `docker compose`, что по README,
на отдельной ВМ; адрес дашборда идёт в поле 2 формы. После дедлайна 27.09 23:59 стенд не трогаем (ссылки не меняются).

## 1. ВМ (консоль Yandex Cloud → Compute Cloud → Создать ВМ)

| Параметр | Значение |
|---|---|
| Образ | Ubuntu 24.04 LTS (или 22.04) |
| vCPU / доля | 2 vCPU, 100 % (не 20 %: иначе сборка и тик прогнозов медленные) |
| RAM / диск | 4–8 ГБ / 30 ГБ SSD |
| Сеть | публичный IP — **автоматически**; прерываемая ВМ — **нет** |
| Доступ | логин `proact`, SSH-ключ — содержимое `~/.ssh/id_ed25519.pub` с ноутбука капитана |

Группа безопасности (входящие, TCP, источник `0.0.0.0/0`): **22, 3000, 8000, 8001, 9201**. Исходящие — все.

## 2. Установка

С ноутбука (Git Bash):

```bash
ssh proact@<IP> 'curl -fsSL https://raw.githubusercontent.com/Lavrentiy123/proact-transport/main/deploy/install.sh | sudo bash -s -- main'
```

После код-фриза — на тег: `... | sudo bash -s -- v1.0` (обновляет стенд на месте). Скрипт в конце печатает ссылки.

## 3. Проверка

```bash
python scripts/smoke_e2e.py --backend http://<IP>:8000 --ml-core http://<IP>:8001 --frontend http://<IP>:3000
```

Ожидается `E2E SMOKE OK`. Дашборд `http://<IP>:3000/` должен показать LIVE и борта на карте через ~1 мин после старта.

## 4. После финала (03.10)

Удалить ВМ и публичный IP — после стартового гранта ВМ тарифицируется с карты.
